## 📌 Mes Projets Principaux

Mes dépôts publics sont documentés et reflètent mon attrait pour l'optimisation, l'algorithmique et le développement "from scratch" :

- **mod1** : Simulation de fluide calculée en temps réel directement sur le GPU (OpenGL / C++).
- **ft_vox** : Moteur voxel optimisé avec génération procédurale de terrain (C++ / Vulkan).
- **kfs** : Noyau d'OS x86 "bare-metal" intégrant un shell, la gestion de la GDT et du mode texte (C / Assembleur x86).
- **maxiRT** : Moteur de rendu ray tracing multi-threadé en temps réel (C).
- **Gomoku** : Intelligence artificielle compétitive avec algorithme MinMax et élagage alpha-bêta optimisé (C++).
- **libgmath** : Bibliothèque mathématique développée de A à Z pour la 3D, compatible OpenGL/Vulkan (C++).
- **transcendence** : Plateforme web multijoueur temps réel (Pong) avec architecture backend complète (Python / Django / PostgreSQL).
